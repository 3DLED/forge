# Movements with no picture

The library is **1536 movements**: 234 curated and 1302 imported from the licensed catalogue. **1408** are illustrated. The **128** below are not, and every one of them is curated.

That split is the whole story. Imported movements came from the set that draws them, so they carry its id and are illustrated by construction. Curated movements were authored here and have to be matched to a picture by name, which only works when the set has that exercise at all.

So the gaps are not scattered, they are whole shelves. Everything that carries, drags or hangs is bare, as is most of the running, because nobody films a sled push.

Generated by `tools/exercise_media_missing.py`.
